# Smart Agriculture Info System

## 项目简介

本项目是一个面向智慧农业场景的环境信息管理系统，基于 STM32、ESP8266、OneNET 云平台和 C# WinForms 上位机实现。系统主要用于农业现场环境数据的采集、传输、展示和控制管理，可应用于果园、蔬菜大棚、稻田等农业场景。

系统通过传感器采集温度、湿度、土壤湿度、水位、光照强度等环境数据，经 STM32 处理后通过 ESP8266 上传至 OneNET 云平台。C# 上位机通过云平台接口读取数据，并提供数据展示、设备控制、历史数据管理和视频监控等功能。

本项目可作为智慧农业环境监测、物联网数据管理和嵌入式上位机系统开发的学习与实践参考。

---

## 项目功能

### 已包含的主要模块

- 环境数据采集  
  通过 STM32 与环境传感器采集农业现场数据。

- ESP8266 无线通信  
  使用 ESP8266 WiFi 模块完成设备联网与云平台通信。

- OneNET 云平台交互  
  设备端可接入 OneNET 云平台，上位机可通过接口读取云端数据。

- C# 上位机显示  
  基于 WinForms 开发上位机界面，用于显示环境监测数据。

- 远程设备控制  
  支持通过上位机向云平台发送控制指令，实现 LED、灌溉设备等执行设备控制。

- 视频监控  
  集成海康威视 SDK，可用于农业现场视频预览。

- 历史数据管理  
  支持对环境数据进行保存，为后续曲线分析和数据导出提供基础。

## 扩展设计功能

在现有系统基础上，可进一步扩展以下功能：

- 阈值设置  
  根据不同农业场景设置温度、湿度、土壤湿度、水位、光照等参数阈值。

- 异常报警  
  当环境数据超过设定阈值时，在上位机界面中进行报警提示。

- 自动控制  
  根据阈值判断结果自动控制灌溉、补光等设备。

- 历史数据曲线  
  对历史环境数据进行曲线展示，便于观察环境变化趋势。

- 数据导出  
  将历史环境数据导出为 CSV 或 Excel 文件，便于后续统计和分析。

- 土壤湿度变化预测  
  根据历史土壤湿度数据和近期变化趋势，预测未来短时间内是否可能出现缺水风险。

- 环境异常风险预测  
  综合温度、湿度、土壤湿度、水位、光照等数据，判断未来是否可能出现温度过高、水位不足、光照不足等异常风险。

系统整体采用分层结构设计，主要包括用户层、应用层、数据层、平台层、通信层和设备层。

```text
用户层
农业管理人员 / 系统维护人员
        ↓
应用层
登录管理 / 场景配置 / 数据显示 / 阈值设置 / 异常报警
自动控制 / 历史曲线 / 数据导出 / 视频监控
土壤湿度预测 / 环境风险预测
        ↓
数据层
实时数据 / 历史数据 / 阈值数据 / 报警记录
设备状态 / 预测结果
        ↓
平台层
OneNET 云平台数据存储与指令转发
        ↓
通信层
ESP8266 WiFi 通信模块
        ↓
设备层
STM32 / 环境传感器 / LED / 灌溉设备 / 摄像头
